# 🛒 SwiftMart – Smart Grocery Delivery App

SwiftMart is a modern grocery delivery application designed to provide **fast, seamless, and intuitive shopping experiences**, similar to platforms like Zepto and Blinkit. Built with a scalable architecture and clean UI, SwiftMart focuses on speed, usability, and real-time interactions.

---

## 🚀 Features

✨ **User-Friendly Interface**

* Clean and minimal UI for effortless navigation
* Smooth animations and responsive design

🛍️ **Product Browsing**

* Categories-based product listing
* Search and filter functionality

⚡ **Flash Deals & Offers**

* Time-based discounts and promotional banners
* Dynamic deal sections

🔔 **Push Notifications**

* Real-time updates for offers and order status (via FCM)

🧾 **Cart & Checkout**

* Add/remove products easily
* Secure and optimized checkout flow

🔐 **Authentication**

* Google Sign-In (via Supabase)
* Secure user sessions

📦 **Order Management**

* Track orders in real-time
* Order history and status updates

---

## 🧑‍💻 Tech Stack

### Frontend

* Flutter 3.x (Dart)
* Riverpod (State Management)

### Backend

* Node.js
* Express.js (REST API)

### Database & Services

* PostgreSQL (via Supabase)
* Firebase Cloud Messaging (FCM)

## ⚙️ Installation

### 1. Clone the Repository

```bash
git clone https://github.com/your-username/swiftmart.git
cd swiftmart
```

### 2. Install Dependencies

```bash
flutter pub get
```

### 3. Run the App

```bash
flutter run
```


## 🏗️ Project Structure

```
lib/
 ├── core/          # Utilities & constants
 ├── features/      # Feature-based modules
 ├── models/        # Data models
 ├── services/      # API & backend services
 ├── providers/     # Riverpod state management
 └── ui/            # Screens & widgets
```
